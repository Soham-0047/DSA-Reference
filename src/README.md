# Inventory Management System

This is a real-world C++ program used in multinational tech companies for managing inventory items. It demonstrates a complex system with features like adding items, removing items, searching, and displaying inventory. This program is designed to be clean, well-documented, and scalable.

## Features
- Add items to inventory with name, quantity, price, and category
- Remove items by name
- Search for items by name
- Display all items in the inventory
- Save inventory to a file
- Load inventory from a file

## How to Use
1. Compile the program using a C++ compiler (e.g., g++)
2. Run the program
3. Use the menu to interact with the inventory system

## File Structure
- `main.cpp`: The main source file containing the program logic
- `README.md`: This file

## Dependencies
- C++11 or later
- Standard library headers
